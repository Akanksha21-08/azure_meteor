# JobVerse - Monolithic MERN Stack Job Portal

A production-grade, monolithic MERN (MongoDB, Express.js, React.js, Node.js) Job Portal Web Application featuring role-based authorization for **Candidates** and **Recruiters**, resume PDF uploads, job search/filter/sort, live application tracking, interview scheduling, and integrated notifications.

---

## Architecture & Technology Stack

- **Frontend**: React 18, Vite, React Router DOM v6, Axios, Lucide Icons, Modern Glassmorphism CSS design system.
- **Backend**: Node.js, Express.js REST API.
- **Database**: MongoDB & Mongoose ORM.
- **Authentication**: JWT (JSON Web Tokens) & Bcrypt password hashing.
- **File Processing**: Multer middleware for PDF resumes and image logo/avatar uploads.
- **Security**: Helmet HTTP headers, CORS protection, Strict Role Authorization Guards.

## Key Features Overview

### Candidate Capabilities
- **Authentication**: Register, Login, JWT protection, Logout, Password Change.
- **Profile Builder**: Personal info, bio, skills, education, work experience, projects, social links (LinkedIn, GitHub, Portfolio), PDF resume upload, avatar photo upload.
- **Job Search & Filters**: Search title/description/company, filter by job type (Full Time, Part Time, Internship, Contract), work mode (Remote, Hybrid, Onsite), sort by salary/date.
- **Application Flow**: One-click apply with attached resume & optional cover letter, single application restriction per job, live status timeline tracking, application withdrawal.
- **Saved Jobs & Interviews**: Save/bookmark jobs, view recruiter-scheduled interviews (online link or offline location), real-time notification feed.

### Recruiter Capabilities
- **Company Branding**: Manage company overview, logo, industry, size, website, contact info.
- **Job Management**: Create job, update job, delete job, toggle active/closed status, view recruiter's posted job pipeline.
- **Applicant Pipeline**: Review candidate profiles, download PDF resumes, read cover letters, update candidate status (Applied, Under Review, Shortlisted, Interview Scheduled, Selected, Rejected).
- **Interview Scheduler**: Schedule interviews with date, time, mode (Online/Offline), meeting link / office address, and candidate notes.

## API Endpoints Summary

| Method | Endpoint | Access | Description |
|---|---|---|---|
| POST | /api/auth/register | Public | Register Candidate or Recruiter |
| POST | /api/auth/login | Public | Authenticate user & get JWT |
| GET | /api/auth/me | Protected | Get current user info |
| GET | /api/jobs | Public | Search, filter, and page active jobs |
| GET | /api/jobs/:id | Public | Get single job details |
| POST | /api/jobs | Recruiter | Create a new job posting |
| PUT | /api/jobs/:id | Recruiter | Edit job details |
| DELETE | /api/jobs/:id | Recruiter | Delete job posting |
| PATCH | /api/jobs/:id/status | Recruiter | Toggle job status (active/closed) |
| POST | /api/applications/apply/:jobId | Candidate | Apply for job |
| GET | /api/applications/candidate | Candidate | Get candidate's applied jobs |
| GET | /api/applications/job/:jobId | Recruiter | Get applicants for job |
| PATCH | /api/applications/:id/status | Recruiter | Change application status |
| PATCH | /api/applications/:id/withdraw | Candidate | Withdraw application |
| POST | /api/interviews/schedule | Recruiter | Schedule interview |
| GET | /api/interviews | Protected | Get user interviews |
| GET | /api/notifications | Protected | Get user notifications & unread count |
